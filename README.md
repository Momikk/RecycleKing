# 回收之王 RecycleKing

面向《最终幻想 XIV》物品栏的 Dalamud 插件，整理回收清单，在出售界面批量出售背包废品。

**当前版本为早期测试版（0.1.1.0）**。

[中文更新记录](CHANGELOG.zh-CN.md) · [English Changelog](CHANGELOG.md)

## 当前功能

- 在 NPC 商店或正在与雇员交互时，背包底部左侧显示“废品回收”；雇员出售列表打开期间固定显示。手动出售、右键菜单或价格调整期间暂时禁用，完成后恢复；离开出售界面后隐藏。点击批量出售普通背包四栏中的可出售清单物品，包含 HQ 和整组数量，再次点击“停止回收”可停止。
- 右键物品，选择带粉色 K 前缀的“加入回收清单”进行登记；NQ/HQ 视为同一物品，已加入的物品不能重复登记。
- 清单按列显示物品图标、名称和“移出清单”按钮，按名称拼音排序，支持滚动查看和逐项移出。
- 单独提供“清空清单”按钮，再次确认后清空。清单自动保存，同一插件配置内共享，重启后保留。
- 在大国防联军“筹备稀有品”原生列表中增加“品级”列，便于查看待交纳装备的物品品级。
- 清单内物品在普通背包中显示与 K 前缀同色的粉色遮罩和 X，NQ/HQ 均匹配；可在窗口顶部关闭。搭配压价之王 0.1.0.21 或更新版本时，粉色标记优先于其蓝框。
- 默认隐藏 AutoRetainer 的军票交纳悬浮框，可在窗口顶部关闭该选项以恢复显示。此功能只隐藏窗口，不停止自动交纳或关闭其他功能；AutoRetainer 更新后可能需要适配。

通过插件设置、`/rking` 或 `/recycleking` 打开原生清单窗口。出售后保留清单，下次仍可回收；移出和清空只删除清单记录。兵装库、穿戴栏及雇员库存不参与批量出售，不能出售的物品跳过。右键入口用于物品库存菜单，不包含聊天链接和任务道具菜单。

已就绪的菜单与数量确认会立即连续处理，减少窗口闪烁；每笔出售仍等待库存和金币变化后再继续。原生窗口仍可能在处理期间出现，完全无闪烁尚未验证。窗口、角色、物品位置或状态变化及无法核对的确认窗口会停止；已提交的出售仍可能完成。遇到停止提示请先处理当前游戏窗口，再决定是否重新点击回收。

## 安装方法

1. 输入 `/xlsettings`，进入 **插件 → 第三方插件**。
2. 添加以下库链，勾选启用并保存：

   ```text
   https://raw.githubusercontent.com/Momikk/DalamudPlugins/main/pluginmaster.json
   ```

3. 输入 `/xlplugins`，搜索 **回收之王** 或 **RecycleKing**，安装并启用。

## 适配与使用条件

需要已启用 Dalamud 的游戏环境。当前版本针对 **Dalamud API 15** 构建，使用国服 XIVLauncherCN 的开发程序集。

已通过编译和离线规则检查。批量出售流程及原生按钮、滚动、主题与缩放、关闭和卸载表现仍需游戏内验收。其他区服尚未验证；游戏或 Dalamud 大版本更新后，请以插件管理器中的兼容状态为准。

源码构建、检查和开发加载说明见[开发文档](docs/development.md)，当前验证范围见[验收记录](docs/verification.md)。
